# Itinerary Redundancy Detector

## Overview
The Itinerary Redundancy Detector identifies previously visited destinations and activities that are similar to experiences in a proposed itinerary. It uses traveller history and preferences to help travel admins reduce unwanted repetition in personalised luxury travel plans.

## Objectives
- Compare proposed itineraries with previous travel history.
- Identify similar activities using semantic similarity.
- Classify destinations and activities as Green, Yellow, or Red.
- Consider traveller preferences and necessary transit stops.
- Suggest alternative activities when repetition should be avoided.

## Proposed Technologies
- Python
- Pandas
- Sentence Transformers
- Scikit-learn
- PostgreSQL
- FastAPI
- Streamlit

## Expected Output
A dashboard showing previous visits, similar activities, colour-coded classifications, explanations, and suggested alternatives for admin review.

## Status
Planning and development. Dataset selection and implementation will progress as the project develops.
