# Multi-Country Itinerary Compatibility Checker

## Overview
This project aims to validate multi-country travel itineraries for luxury travellers visiting South Asia. It helps travel admins identify impractical destination sequences, unnecessary backtracking, travel-time constraints, connection issues, visa requirements, and seasonal closures.

## Objectives
- Validate the order of destinations in an itinerary.
- Identify potential route and connection conflicts.
- Flag excessive travel time and unnecessary backtracking.
- Highlight visa, border, and seasonal requirements that need verification.
- Generate an itinerary compatibility report for admin review.

## Proposed Technologies
- Python
- Pandas
- FastAPI
- PostgreSQL
- Streamlit
- External travel information APIs, where available

## Expected Output
A compatibility report showing the proposed destination sequence, potential route issues, missing connection information, travel warnings, requirements requiring verification, and suggested changes.

## Status
Planning and development. The implementation and data sources will be finalised as the project progresses.
