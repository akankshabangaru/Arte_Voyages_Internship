# Documentation

## Overview
This folder contains the technical documentation for the Arte Voyages AI/ML project, focused on luxury travel and tourism for high-net-worth individuals (HNIs) visiting South Asia.

## Contents

### Technical Approach Document

The document describes the proposed technical approaches for all six use cases across three project modules:

**Part 1: Itinerary Compatibility and Redundancy — Akanksha**
- Multi-Country Itinerary Compatibility Checker
- Itinerary Redundancy Detector

**Part 2: Hotel Rate and Inquiry Extraction — Harsha**
- Hotel Rate Prediction and Demand Analysis
- Multilingual Travel Inquiry Information Extractor

**Part 3: Trip Risk Monitoring and Partner Prediction — Charanjeeth**
- Continuous Trip Risk Monitoring
- Partner Confirmation Prediction and Sequencing

## Purpose
The document outlines each use case's objectives, problem statement, workflow, datasets and data sources, proposed technologies, expected outputs, and limitations.

## Status
The technical approach document records the proposed implementation plans. Technology choices and approaches may change as development progresses.
